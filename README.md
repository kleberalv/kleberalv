## 💼 Sobre mim

- 🚀 Fundei a **KCode**, que desenvolve, publica e mantém sistemas sob medida para empresas e profissionais liberais.
- 🧱 Gosto de arquitetura limpa: **monólito modular, CQRS**, camadas verificadas por testes e análise estática no nível máximo.
- 🔐 Levo segurança a sério: verificação em duas etapas, auditoria, licenças assinadas digitalmente e dados protegidos por padrão.
- ⚙️ Entrego com **CI/CD**: a cada versão, os testes rodam, as migrações são aplicadas e o sistema vai para produção sozinho.

## 🏗️ O que estou construindo na KCode

| Projeto | O que é | Stack |
|---|---|---|
| **KCode Hub** | Centro de controle dos sistemas da KCode: clientes, contratos, cobrança, uso, suporte e licenças assinadas (Ed25519) que liberam ou bloqueiam cada sistema, no site e na API, mesmo com o Hub fora do ar. | Laravel 13 · Angular 22 · PostgreSQL · Vercel |
| **SDK da KCode** | Pacotes que ligam qualquer sistema ao Hub em poucas linhas: tela de bloqueio, somente consulta e medição de uso, para Laravel, Node, React e Angular. | PHP · TypeScript · Node · React · Angular |
| **Sistema da Advocacia** | Página e área logada de um escritório de advocacia em produção, com conteúdo editável, gestão de processos e licença controlada pelo Hub. | Laravel · React · Supabase · Vercel |
